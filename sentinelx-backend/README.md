# SentinelX

### Intelligent Application Security Assessment & Vulnerability Management Platform

SentinelX is a full-stack security assessment platform designed to help security teams evaluate an application's security posture, identify vulnerabilities, analyze risk, collect evidence, and track remediation and retesting.

## 🚀 Key Features

- Security Assessment Management
- Security Test Execution
- Vulnerability Detection & Management
- Attack Surface Mapping
- Risk & Severity Analysis
- Evidence / Proof-of-Concept Management
- Remediation Tracking
- Retesting & PASS/FAIL Verification
- Security Assessment Reports
- Compliance Tracking
- Audit Logging
- AI Security Assistant
- Interactive Security Dashboard

## 🛠️ Technology Stack

### Frontend
- React
- TypeScript
- Responsive UI

### Backend
- Node.js
- Express.js
- RESTful APIs
- JSON-based data layer

### Deployment
- Docker
- Cloud Run

## 🔐 Security Assessment Workflow

Scope → Security Tests → Evidence → Findings → Risk Analysis → Remediation → Retesting

## 🏗️ Architecture

SentinelX follows a layered architecture consisting of:

1. Presentation Layer
2. REST API Layer
3. Security Assessment Layer
4. Vulnerability & Risk Management Layer
5. Evidence & Reporting Layer
6. Continuous Validation Layer

## 🤖 AI Security Assistant

The platform includes an AI-assisted interface that helps users understand security findings, assessment information, remediation actions, and security-related questions.

## 📊 Dashboard

The dashboard provides an overview of:

- Security assessment score
- Open and resolved findings
- Severity distribution
- Test execution status
- Retest results
- Security posture progression
